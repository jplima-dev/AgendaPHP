# agendaPHP

Sistema de agenda desenvolvido em PHP como projeto acadêmico.

## Sobre o projeto

O agendaPHP é um sistema para gerenciamento de contatos, desenvolvido para colocar em prática conhecimentos de desenvolvimento web e banco de dados.

## Tecnologias utilizadas

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/jplima-dev/agendaPHP.git
```

2. Coloque o projeto no diretório do seu servidor web.

3. Crie um banco de dados MySQL para o projeto.

4. Importe o arquivo SQL do projeto para criar as tabelas do banco de dados.

5. Configure os dados de conexão com o banco de dados no arquivo de configuração do projeto.

6. Inicie o Apache e o MySQL e acesse o projeto pelo navegador.
